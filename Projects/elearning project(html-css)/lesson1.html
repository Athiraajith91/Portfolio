Lesson 1: Introduction to HTML

HTML (HyperText Markup Language) is the building block of all websites. In this lesson, you will understand what HTML is and how to create your first basic webpage.

📘 What is HTML?

HTML is a markup language used to structure content on the web. It tells the browser how to display text, images, links, and layout.

📝Basic HTML Structure

Every webpage starts with this basic layout:

                <!DOCTYPE html>
                <html>
                <head>
                <title>My First Page</title>
                </head>
                <body>
                <h1>Hello World</h1>
                </body>
                </html>

🏷 Common HTML Tags

  • <h1> – Main Heading
  • <p> – Paragraph
  • <img> – Image
  • <a> – Hyperlink
  • <div> – Division/Container
